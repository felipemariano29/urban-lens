Objetivo da demonstracao:
- mostrar ingestao de um snapshot pequeno

O que deixar pronto antes do professor chegar:
- containers ja iniciados
- frontend ja iniciado
- uma consulta curta feita antes para "aquecer" o Ollama
- abas abertas:
  - terminal
  - http://localhost:3001
  - http://localhost:8000/docs
  - http://localhost:3000

Comandos de preparacao:
- make up
- make frontend
- make urls

Autenticacao para chamadas da API:
- antes de testar endpoints no Swagger ou em chamadas manuais, use este header:
  - `X-API-Key: urban-lens-api-key-2026`
- no Swagger:
  - clique em `Authorize`
  - preencha o campo de API key com `urban-lens-api-key-2026`
- em PowerShell ou curl:
  - envie o header `X-API-Key` com esse mesmo valor

Buscas semanticas sugeridas para esta pasta leve:
- "burglary in City of London in 2026-01"
- "other theft in City of London in 2026-01"
- "anti social behaviour in Cumbria in 2026-01"
- "violence and sexual offences in Cumbria in 2026-01"

Justificativa dessas queries:
- City of London tem bastante "other theft", "shoplifting" e "burglary"
- Cumbria tem bastante "violence and sexual offences", "public order", "anti-social behaviour" e "burglary"
- isso reduz o risco de a consulta retornar chunks pouco relevantes na demonstracao

Fluxo manual pronto em PowerShell, se voce preferir nao usar o Swagger:

$headers = @{
  "X-API-Key" = "urban-lens-api-key-2026"
  "Content-Type" = "application/json"
}

$queryBody = @{
  query = "burglary in City of London in 2026-01"
  top_k = 3
} | ConvertTo-Json

Invoke-RestMethod -Method Post -Uri "http://localhost:8000/api/v1/query" -Headers $headers -Body $queryBody

$chatBody = @{
  query = "What are the main crime patterns in City of London and Cumbria in 2026-01?"
  filters = @{
    reference_month = "2026-01"
  }
  top_k = 5
  model = "llama3"
} | ConvertTo-Json -Depth 5

Invoke-RestMethod -Method Post -Uri "http://localhost:8000/api/v1/chat/query" -Headers $headers -Body $chatBody

Invoke-RestMethod -Method Get -Uri "http://localhost:8000/api/v1/metadata?source=gold/rag/crime_chunks" -Headers @{ "X-API-Key" = "urban-lens-api-key-2026" }
